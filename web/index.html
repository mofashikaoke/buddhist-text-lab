支持 OpenAI 及兼容 Chat Completions 协议的接口。填写服务商提供的地址、模型名和 API Key。

未勾选保存时，密钥仅保留到程序退出。这里填写 API Key，不填写网页账号密码。更换接口地址后，已有密钥不会自动发送给新地址。连接测试也会调用模型。
